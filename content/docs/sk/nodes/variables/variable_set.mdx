---
title: "Set Variable"
---

Updates a graph variable during execution

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec | Žiadna | Starts updating the variable. |
| Variable | variable | Žiadna | Variable to update. |
| Value | string | Žiadna | New value to store in the variable. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after the variable is updated. |
| Variable | variable | Reference to the updated variable. |

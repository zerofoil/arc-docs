---
title: "Get Variable"
---

Reads a graph variable as typed data

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Variable | variable | Žiadna | Variable to read. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Variable | variable | Reference to the variable that was read. |
| Value | string | Current value stored in the variable. |

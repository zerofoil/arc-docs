---
title: "Divide (÷)"
---

Divides A by B, division by zero returns 0

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| A | number | Žiadna | Number to divide. |
| B | number | Žiadna | Number to divide by. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Result | number | A divided by B, or zero when B is zero. |

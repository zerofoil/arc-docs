---
title: "Clamp"
---

Restricts a value between a minimum and maximum

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Value | number | Žiadna | Number to restrict to the selected range. |
| Minimum | number | Žiadna | Lowest allowed result. |
| Maximum | number | 1 | Highest allowed result. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Result | number | Input limited to the minimum and maximum. |

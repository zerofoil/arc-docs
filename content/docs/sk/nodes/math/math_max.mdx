## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| A | number | Žiadna | First number to compare. |
| B | number | Žiadna | Second number to compare. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Result | number | Larger of A and B. |

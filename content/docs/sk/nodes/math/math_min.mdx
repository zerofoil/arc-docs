Returns the smaller number

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| A | number | 0 | First number to compare. |
| B | number | 0 | Second number to compare. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Result | number | Smaller of A and B. |

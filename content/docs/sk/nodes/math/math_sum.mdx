---
title: "Sum"
---

Adds up to 50 values. Connect the last input to reveal another.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| A | number | 0 | First number included in the sum. |
| B | number | 0 | Second number included in the sum. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Result | number | Sum of the connected numbers. |

---
title: "Switch / Case"
---

Compares one value with up to 50 cases and runs the first matching branch, or Default when none match.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec | Žiadna | Checks the value against each case in order. |
| Value | arg | Žiadna | Value compared with the configured cases. |
| Case 1 | string | Žiadna | First value to compare against the input. |
| Case 2 | string | Žiadna | Second value to compare against the input. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Case 1 | exec | Runs when the input matches Case 1. |
| Case 2 | exec | Runs when the input matches Case 2. |
| Default | exec | Runs when no case matches the input. |

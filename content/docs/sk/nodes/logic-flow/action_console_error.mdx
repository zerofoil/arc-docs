---
title: "Console Error"
---

Writes a message to the Studio console at error level.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec | Žiadna | Writes the message to the error log. |
| Message | string | Žiadna | Text to write to the Studio console. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after the error message is logged. |

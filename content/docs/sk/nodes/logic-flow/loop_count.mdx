---
title: "For Count"
---

Runs the Body branch once per iteration, then continues from Completed. Iterations are capped at 1,000 per run.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec | Žiadna | Starts the counted loop. |
| Count | number | 1 | Number of times to run the Body branch. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Body | exec | Runs once for each loop iteration. |
| Completed | exec | Runs after all iterations finish. |
| Index (0-based) | number | Zero-based index of the current iteration. |

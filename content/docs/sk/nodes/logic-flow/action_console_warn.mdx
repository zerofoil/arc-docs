---
title: "Console Warn"
---

Writes a message to the Studio console at warn level.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec | Žiadna | Writes the message to the warning log. |
| Message | string | Žiadna | Text to write to the Studio console. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after the warning is logged. |

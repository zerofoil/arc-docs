---
title: "Wire Extender"
---

Passes execution or any typed data value straight through. Use it to route wires neatly around a busy canvas.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec In | exec |  | Execution flow to pass through the node. |
| Any Value 1 | any |  | Any typed data value to pass through the node. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec Out | exec | Execution flow passed through unchanged. |
| Any Value 1 | any | Data value passed through unchanged. |

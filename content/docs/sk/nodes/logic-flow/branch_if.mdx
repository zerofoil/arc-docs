---
title: "Branch (If / Else)"
---

Splits execution flow based on a boolean condition

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec | Žiadna | Evaluates the condition and selects an execution branch. |
| Condition | boolean | Žiadna | Boolean value used to choose the True or False branch. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| True | exec | Runs when the condition is true. |
| False | exec | Runs when the condition is false. |

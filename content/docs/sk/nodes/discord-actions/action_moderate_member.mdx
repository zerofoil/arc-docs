---
title: "Moderate Member"
---

Times out, kicks, bans, or unbans a server member. Route failures through the Failed output.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts Moderate Member. |
| Server ID | string |  | ID of the server containing the member to moderate. |
| User ID | string |  | ID of the member to moderate. |
| Action | string | timeout | Change to apply. |
| Timeout (minutes) | number | 10 | Timeout length in minutes. |
| Ban message deletion (seconds) | number | 0 | Recent message history to delete, in seconds. |
| Reason | string |  | Reason recorded in the audit log. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Succeeded | exec | Continues after Moderate Member completes. |
| Failed | exec | Runs when Discord rejects the moderation action. |
| Success | boolean | Whether the action completed successfully. |
| Error | string | Error message returned when the action fails. |

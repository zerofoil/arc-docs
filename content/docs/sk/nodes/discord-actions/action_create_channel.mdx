---
title: "Create Channel"
---

Creates a text, voice, category, announcement, stage, forum, or media channel. Requires Manage Channels.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec | Žiadna | Starts Create Channel. |
| Server ID | string | Žiadna | ID of the server where the channel will be created. |
| Name | string | Žiadna | Name to assign. |
| Channel Type | number | Žiadna | Discord channel type value. |
| Category ID | string | Žiadna | Category ID alias for the parent channel. |
| Parent ID | string | Žiadna | Optional parent channel or category ID. |
| Permission Overwrites | object | Žiadna | Channel permission overwrites to apply. |
| Topic | string | Žiadna | Channel topic to set. |
| Channel Flags | number | Žiadna | Channel flags to set. |
| Slowmode (seconds) | number | Žiadna | Slowmode delay in seconds. |
| Bitrate (bits/sec) | number | 64000 | Voice channel bitrate in bits per second. |
| User Limit | number | Žiadna | Maximum number of users allowed in the voice channel. |
| Position | number | Žiadna | Position of the new channel in the channel list. |
| Voice Region | string | Žiadna | Voice region for the new channel, or blank for automatic selection. |
| Voice Video Quality Mode | number | 1 | Voice video quality mode value. |
| Default Thread Archive (minutes) | number | 1440 | Default thread auto archive time in minutes. |
| Thread Slowmode (seconds) | number | Žiadna | Default thread slowmode in seconds. |
| Forum Tags | object | Žiadna | Forum tags to make available. |
| Age Restricted | boolean | Žiadna | Whether to mark the channel as age restricted. |
| Audit Log Reason | string | Žiadna | Reason recorded in the audit log. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after Create Channel completes. |
| Channel Object | object | New channel record returned by Discord. |
| Channel ID | string | ID of the created channel. |
| Channel ID | string | ID of the returned channel. |
| Success | boolean | Whether the action completed successfully. |

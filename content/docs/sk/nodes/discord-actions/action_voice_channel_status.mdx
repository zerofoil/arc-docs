---
title: "Set Voice Channel Status"
---

Sets or clears a voice channel status. Requires Set Voice Channel Status, Manage Channels may also be required.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec | Žiadna | Starts Set Voice Channel Status. |
| Voice Channel ID | string | Žiadna | ID of the voice channel to update. |
| Status (blank clears) | string | Žiadna | Status text to set, or blank to clear the current status. |
| Audit Log Reason | string | Žiadna | Reason recorded in the audit log. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after Set Voice Channel Status completes. |
| Success | boolean | Whether the action completed successfully. |

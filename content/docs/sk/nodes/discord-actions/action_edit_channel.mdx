---
title: "Edit Channel"
---

Changes a channel name, topic, category, slowmode, or permissions. Requires Manage Channels.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts Edit Channel. |
| Channel ID | string |  | ID of the channel to edit. |
| Thread ID (Optional) | string |  | Optional thread ID to edit. |
| Name | string |  | Name to assign. |
| Topic | string |  | Channel topic to set. |
| Category ID | string |  | ID of the parent channel or category. |
| Category ID (Alias) | string |  | ID of the parent category. |
| Permission Overwrites | object |  | Channel permission overwrites to apply. |
| Position | number |  | Position of the channel in the channel list. |
| Channel Flags | number |  | Channel flags to set. |
| Slowmode (seconds) | number | 0 | Slowmode delay in seconds. |
| Thread Slowmode (seconds) | number |  | Default thread slowmode in seconds. |
| Forum Tags | object |  | Forum tags to make available. |
| Age restricted | boolean | false | Whether to mark the channel as age restricted. |
| Voice bitrate | number | 64000 | Voice channel bitrate in bits per second. |
| Voice user limit | number | 0 | Maximum number of users allowed in the voice channel. |
| Voice Region | string |  | Voice region for the channel, or blank for automatic selection. |
| Voice video quality mode | number |  | Voice video quality mode value. |
| Thread auto archive (minutes) | number |  | Default thread auto archive time in minutes. |
| Archived | boolean | false | Whether to archive the thread. |
| Locked | boolean | false | Whether to lock the thread. |
| Members can invite | boolean | true | Whether thread members can invite others. |
| Thread auto archive (minutes) | number | 1440 | Thread auto archive time in minutes. |
| Audit Log Reason | string |  | Reason recorded in the audit log. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after Edit Channel completes. |
| Channel Object | object | Updated channel record returned by Discord. |
| Channel ID | string | ID of the returned channel. |
| Channel ID | string | ID of the channel to edit. |
| Success | boolean | Whether the action completed successfully. |

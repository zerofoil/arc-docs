---
title: "Request Voice Join / Leave"
---

Requests a Gateway voice-state change. Joining does not create an audio connection or play audio.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec | Žiadna | Starts Request Voice Join / Leave. |
| Server ID | string | Žiadna | ID of the server containing the voice channel. |
| Voice Channel ID (blank leaves) | string | Žiadna | Voice channel ID to join, or blank to leave voice. |
| Self Mute | boolean | Žiadna | Whether to join voice muted. |
| Self Deafen | boolean | Žiadna | Whether to join voice deafened. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after Request Voice Join / Leave completes. |
| Success | boolean | Whether the action completed successfully. |

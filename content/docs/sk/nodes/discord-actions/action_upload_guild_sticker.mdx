---
title: "Upload Server Sticker"
---

Uploads a PNG, APNG, or GIF sticker to a server. Requires Create Expressions. File limit is 512 KiB.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec | Žiadna | Starts uploading a sticker to the server. |
| Server ID | string | Žiadna | ID of the server to receive the sticker. |
| Sticker Name | string | Žiadna | Name to assign. |
| Description | string | Žiadna | Description to assign. |
| Tags (emoji) | string | ✨ | Emoji tags used to identify the sticker. |
| Sticker File | object | Žiadna | Files to attach to the message. |
| Audit Log Reason | string | Žiadna | Reason recorded in the audit log. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after Upload Server Sticker completes. |
| Sticker ID | string | ID of the created sticker. |
| Sticker Name | string | Name of the created sticker. |
| Success | boolean | Whether the action completed successfully. |

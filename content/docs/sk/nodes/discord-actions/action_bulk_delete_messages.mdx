---
title: "Bulk Delete Messages"
---

Deletes 2 to 100 messages from a server channel. Messages older than 14 days cannot be bulk deleted. Requires Manage Messages.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec | Žiadna | Starts Bulk Delete Messages. |
| Channel ID | string | Žiadna | ID of the channel containing the messages. |
| Message IDs | object | Žiadna | IDs of the messages to delete. |
| Audit Log Reason | string | Žiadna | Reason recorded in the audit log. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after Bulk Delete Messages completes. |
| Deleted Count | number | Number of messages deleted. |
| Success | boolean | Whether the action completed successfully. |

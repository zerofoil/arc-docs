---
title: "Create Role"
---

Creates a role with a name, RGB color number, and mentionable setting. Requires Manage Roles.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec | Žiadna | Starts Create Role. |
| Server ID | string | Žiadna | ID of the server to receive the new role. |
| Name | string | new role | Name to assign. |
| Color (RGB number) | number | Žiadna | Role color as an RGB integer. |
| Permissions Bitfield | string | 0 | Role permission bitfield. |
| Show separately | boolean | Žiadna | Whether to show the role separately in the member list. |
| Mentionable | boolean | Žiadna | Whether users can mention the role. |
| Audit Log Reason | string | Žiadna | Reason recorded in the audit log. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after Create Role completes. |
| Role ID | string | ID of the created role. |
| Success | boolean | Whether the action completed successfully. |

---
title: "Get Guild Member Permissions"
---

Gets a member's computed guild permissions from their roles and the @everyone role.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec | Žiadna | Starts Get Guild Member Permissions. |
| Server ID | string | Žiadna | ID of the server whose permissions to check. |
| User ID | string | Žiadna | ID of the member whose permissions to check. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after Get Guild Member Permissions completes. |
| Permissions Bitfield | string | Calculated permission bitfield. |
| Success | boolean | Whether the action completed successfully. |

---
title: "Respond to Autocomplete"
---

Returns up to 25 suggestions from a wired array of name and value objects.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec | Žiadna | Starts Respond to Autocomplete. |
| Interaction ID | string | Žiadna | ID of the interaction to respond to. |
| Interaction Token | string | Žiadna | Token used to respond to the interaction. |
| Suggestions | object | Žiadna | Suggestions to return for the focused command option. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after Respond to Autocomplete completes. |
| Suggestions Sent | number | Number of suggestions sent to Discord. |
| Success | boolean | Whether the action completed successfully. |

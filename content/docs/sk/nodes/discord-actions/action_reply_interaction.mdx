---
title: "Reply to Interaction"
---

Responds to an interaction within Discord’s 3 second initial response window, or edits a deferred response

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec | Žiadna | Starts Reply to Interaction. |
| Application ID | string | Žiadna | ID of the application that owns the interaction. |
| Interaction ID | string | Žiadna | ID of the interaction to respond to. |
| Interaction Token | string | Žiadna | Token used to respond to the interaction. |
| Reply Content | string | Žiadna | Text to include in the interaction reply. |
| Embed (Optional) | embed | Žiadna | Embed to include with the message. |
| Components (Optional) | object | Žiadna | Message components to send or update. |
| Files (optional) | object | Žiadna | Files to attach to the message. |
| Ephemeral (Hidden) | boolean | Žiadna | Whether to hide the interaction response from other users. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after Reply to Interaction completes. |
| Interaction ID | string | ID of the interaction that was handled. |
| Application ID | string | ID of the application that owns the interaction. |
| Interaction Token | string | Token used to continue responding to the interaction. |
| Message ID | string | ID of the message created by the action. |
| Response Message | object | Message created as the interaction reply. |
| Success | boolean | Whether the action completed successfully. |

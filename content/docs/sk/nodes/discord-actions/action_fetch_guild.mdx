---
title: "Get Server Info"
---

Fetches a Discord server and exposes its full server object, owner, features, and common settings

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts Get Server Info. |
| Server ID | string |  | ID of the server to fetch. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after Get Server Info completes. |
| Server Object | object | Full server record returned by Discord. |
| Server ID | string | ID of the returned server. |
| Name | string | Name to assign. |
| Owner ID | string | ID of the server owner. |
| Description | string | Description to assign. |
| Icon Hash | string | Icon hash for the returned server. |
| Approx. Members | number | Approximate number of server members. |
| Features | object | Features enabled for the server. |
| Preferred Locale | string | Preferred locale for the server. |
| Verification Level | number | Server verification level value. |
| Success | boolean | Whether the action completed successfully. |

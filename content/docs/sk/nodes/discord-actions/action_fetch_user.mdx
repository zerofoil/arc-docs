---
title: "Get User Info"
---

Fetches a Discord user profile and exposes both the full user object, avatar, and common profile fields

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec | Žiadna | Starts Get User Info. |
| User ID | string | Žiadna | ID of the user to fetch. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after Get User Info completes. |
| User Object | object | Full user record returned by Discord. |
| User ID | string | ID of the returned user. |
| Username | string | Username of the returned user. |
| Display Name | string | Display name of the returned user. |
| Discriminator | string | Legacy discriminator of the returned user. |
| Avatar Hash | string | Avatar hash of the returned user. |
| Avatar URL | string | URL of the returned user avatar. |
| Banner Hash | string | Banner hash of the returned user. |
| Banner URL | string | URL of the returned user banner. |
| Is Bot | boolean | Whether the returned user is a bot. |
| Public Flags | number | Public user flag bitfield. |
| Success | boolean | Whether the action completed successfully. |

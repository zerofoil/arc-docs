---
title: "Deploy Slash Commands"
---

Deploys workspace slash commands when triggered by a server manager with Manage Server or Administrator.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec | Žiadna | Starts Deploy Slash Commands. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after Deploy Slash Commands completes. |
| Commands Deployed | number | Number of slash commands deployed. |
| Succeeded | boolean | Whether the action completed successfully. |
| Error | string | Error message returned when the action fails. |

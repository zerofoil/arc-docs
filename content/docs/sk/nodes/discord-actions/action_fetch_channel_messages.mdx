---
title: "Get Channel Messages"
---

Fetches up to 100 recent messages from a channel. Requires View Channel and Read Message History.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec | Žiadna | Starts Get Channel Messages. |
| Channel ID | string | Žiadna | ID of the channel to fetch messages from. |
| Limit | number | 50 | Maximum number of messages to fetch. |
| Before Message ID | string | Žiadna | Fetch messages older than this message ID. |
| After Message ID | string | Žiadna | Fetch messages newer than this message ID. |
| Around Message ID | string | Žiadna | Fetch messages around this message ID. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after Get Channel Messages completes. |
| Messages | array | Messages fetched from the channel. |
| Count | number | Number of messages returned. |
| First Message | object | Oldest message in the returned results. |
| Last Message | object | Newest message in the returned results. |
| Success | boolean | Whether the action completed successfully. |

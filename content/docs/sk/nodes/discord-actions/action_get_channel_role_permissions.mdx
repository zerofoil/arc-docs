---
title: "Get Channel Role Permissions"
---

Gets a role's channel permissions together with @everyone, applying channel overwrites.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts Get Channel Role Permissions. |
| Channel ID | string |  | ID of the channel whose permissions to check. |
| Role ID | string |  | ID of the role whose permissions to check. |
| Apply Implicit Masking | boolean | true | Apply Discord implied permission rules to the result. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after Get Channel Role Permissions completes. |
| Permissions Bitfield | string | Calculated permission bitfield. |
| Success | boolean | Whether the action completed successfully. |

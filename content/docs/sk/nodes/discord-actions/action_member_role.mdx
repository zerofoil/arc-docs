---
title: "Set Member Role"
---

Adds or removes a role from a guild member. Requires Manage Roles.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts Set Member Role. |
| Server ID | string |  | ID of the server containing the member. |
| User ID | string |  | ID of the member whose role will change. |
| Role ID | string |  | ID of the role to assign or remove. |
| Operation | string | add | Change to apply. |
| Audit Log Reason | string |  | Reason recorded in the audit log. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after Set Member Role completes. |
| Success | boolean | Whether the action completed successfully. |

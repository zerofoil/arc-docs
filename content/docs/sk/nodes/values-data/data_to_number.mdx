---
title: "To Number"
---

Parses a complete decimal number, including sign and exponent. Invalid or non-finite input returns 0, check Valid before using it.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Text | string | Žiadna | Text containing a decimal number to parse. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Number | number | Parsed finite number, or zero when parsing fails. |
| Valid | boolean | True when the input is a valid finite number. |

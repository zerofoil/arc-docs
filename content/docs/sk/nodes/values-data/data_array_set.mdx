---
title: "Edit Array Item"
---

Returns a copy of the array with an existing zero-based index replaced. The source array is unchanged.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Array | object | Žiadna | Array to copy and update. |
| Index | number | Žiadna | Zero-based position of the item to replace. |
| New Item | arg | Žiadna | Value to place at the selected index. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Array | object | Copy of the array with the selected item replaced. |
| Updated | boolean | True when an existing array item was replaced. |

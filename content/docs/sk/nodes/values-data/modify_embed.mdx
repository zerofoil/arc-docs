---
title: "Modify Embed"
---

Updates specific fields on an existing embed without rebuilding it

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Base Embed | embed | Žiadna | Embed to copy and update. |
| Title (Optional) | string | Žiadna | Optional replacement title. |
| Description (Optional) | string | Žiadna | Optional replacement description. |
| Hex Color (#, optional) | string | Žiadna | Optional replacement hex color. |
| Image URL (Optional) | string | Žiadna | Optional replacement image URL. |
| Thumbnail URL (Optional) | string | Žiadna | Optional replacement thumbnail URL. |
| Footer Text (Optional) | string | Žiadna | Optional replacement footer text. |
| Author Name (Optional) | string | Žiadna | Optional replacement author name. |
| Field Name (Optional) | string | Žiadna | Optional field name to add or update. |
| Field Value (Optional) | string | Žiadna | Optional field value to add or update. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Embed | embed | Updated embed with the selected fields changed. |

---
title: "Get Modal Value"
---

Reads a submitted modal field by custom ID, multi-select fields return arrays.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Submitted Values | object |  | Submitted values from the modal interaction. |
| Field Custom ID | string |  | Custom ID of the submitted modal field. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Value | object | Value submitted for the matching field. |
| Found | boolean | True when a field with this custom ID was submitted. |

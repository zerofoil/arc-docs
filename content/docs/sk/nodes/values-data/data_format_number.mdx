---
title: "Format Number"
---

Formats a finite number with locale grouping, decimal, percent, or currency style. Percent style scales the number by 100.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Value | number | 0 | Finite number to format. |
| Locale | string | en-US | Locale used for grouping and decimal symbols. |
| Style | string | decimal | Number display style. |
| Currency | string | USD | Currency code used for currency style. |
| Minimum decimals | number | 0 | Minimum number of fraction digits to display. |
| Maximum decimals | number | 2 | Maximum number of fraction digits to display. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Formatted | string | Formatted number text. |
| Valid | boolean | True when the number and formatting options are valid. |

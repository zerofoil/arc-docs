title: "Embed Builder"
---

Constructs a rich Discord embed object

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Title | string | Žiadna | Embed title text. |
| Description | string | Žiadna | Main description text for the embed. |
| URL | string | Žiadna | URL opened when the title is clicked. |
| Hex Color (#) | string | #5865F2 | Embed accent color as a hex value. |
| Author | string | Žiadna | Author name shown above the description. |
| Author URL | string | Žiadna | URL opened when the author name is clicked. |
| Author Icon URL | string | Žiadna | URL of the author icon image. |
| Footer Text | string | Žiadna | Footer text shown at the bottom. |
| Footer Icon URL | string | Žiadna | URL of the footer icon image. |
| Thumbnail URL | string | Žiadna | URL of the thumbnail image. |
| Image URL | string | Žiadna | URL of the main embed image. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Embed | embed | Built Discord embed object. |
| Components | object | Message components attached to the embed. |

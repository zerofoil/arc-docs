---
title: "Get Array Item"
---

Reads an item by its zero-based index. Check Found before using the result.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Array | object |  | Array to read an item from. |
| Index | number | 0 | Zero-based position of the item to read. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Item | arg | Item at the selected index, when found. |
| Found | boolean | True when the selected index exists in the array. |

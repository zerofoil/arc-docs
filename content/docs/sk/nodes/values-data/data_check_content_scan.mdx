---
title: "Check Content Scan"
---

Checks a Discord Message object for explicit, gore, or self-harm content scan flags on attachments, embeds, and Components V2 media. Flags may arrive later in On Message Updated, so missing flags do not mean the message is safe.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Message | object | [object Object] | Discord message whose attachments, embeds, and media to check. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Contains Explicit Content | boolean | True when an item has an explicit content scan flag. |
| Contains Gore Content | boolean | True when an item has a gore content scan flag. |
| Contains Self-Harm Content | boolean | True when an item has a self-harm content scan flag. |
| Contains Flagged Content | boolean | True when any checked item has a content scan flag. |
| Scan Metadata Present | boolean | True when scan metadata is available on the message. |
| Items With Scan Flags | number | Number of items with scan metadata. |
| Flagged Items | number | Number of items with one or more scan flags. |
| Findings | array | Details for each item with scan metadata. |

---
title: "To Text"
---

Converts a value to text. Objects and arrays become JSON, null becomes empty text. Check Valid if the value cannot be serialized.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Value | arg | Žiadna | Value to convert to text. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Text | string | Text representation of the input value. |
| Valid | boolean | True when the input can be converted to text. |

---
title: "Find Array Item"
---

Finds the first item equal to Value. Set Path to compare a nested property, such as id or user.name.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Array | object | Žiadna | Array to search. |
| Property path | string | Žiadna | Optional property path to compare on each item. |
| Match value | arg | Žiadna | Value to find in the array or selected property. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Item | arg | First matching item, when found. |
| Index | number | Zero-based position of the first matching item. |
| Found | boolean | True when a matching item exists. |

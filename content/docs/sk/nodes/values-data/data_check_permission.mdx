---
title: "Check Permission"
---

Checks whether a permission bitfield includes every selected Discord permission. Connect the Permissions Bitfield output from a guild or channel permission node.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Permissions Bitfield | string | Žiadna | Permission bitfield to check. |
| Permissions | arg | VIEW_CHANNEL | Permission or permissions that must all be present. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Has Permission | boolean | True when the bitfield includes every selected permission. |
| Valid Bitfield | boolean | True when the input is a valid permission bitfield. |

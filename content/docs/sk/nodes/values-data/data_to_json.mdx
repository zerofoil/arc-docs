---
title: "To JSON"
---

Serializes a value to compact JSON. Cyclic or unsupported values return an empty string and valid=false.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Value | object |  | Value to serialize as JSON. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| JSON | string | Compact JSON text for the input value. |
| Valid | boolean | True when the value can be serialized. |

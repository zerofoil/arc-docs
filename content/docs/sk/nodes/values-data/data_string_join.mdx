---
title: "Join Text"
---

Joins array values into one string using the separator.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Items | object |  | Array values to join into text. |
| Separator | string | ,  | Text placed between each array value. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Text | string | Array values joined into one text string. |

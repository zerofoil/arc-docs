---
title: "Combine Arrays"
---

Concatenates connected arrays in input order into a new array. Use another Create Array node for more than 50 individual items.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Array 1 | object | Žiadna | First array to combine. |
| Array 2 | object | Žiadna | Second array to append after the first. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Array | object | New array containing the items from both inputs in order. |
| Length | number | Number of items in the combined array. |

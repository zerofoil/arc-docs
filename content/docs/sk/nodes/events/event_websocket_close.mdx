---
title: "On WebSocket Close"
---

Runs when a WebSocket connection closes. Set Filter Connection ID to listen for one connection.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Filter Connection ID | string | Žiadna | Only handle events from this connection ID. Leave blank for all connections. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Runs when a WebSocket connection closes. |
| Connection ID | string | ID of the WebSocket connection. |
| Code | number | Invite code. |
| Reason | string | Reason recorded with the audit log entry. |
| Was Clean | boolean | Whether the WebSocket connection closed cleanly. |

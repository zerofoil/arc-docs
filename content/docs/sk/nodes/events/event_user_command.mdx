---
title: "On User Command"
---

Fires when an app user context menu command is invoked on a user

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Runs when an app user context menu command is invoked on a user. |
| Command Name | string | Name of the invoked application command. |
| Target User ID | string | ID of the user selected by the command. |
| Target User | object | User selected by the command. |
| Target Member | object | Server member selected by the command. |
| User ID | string | ID of the user who triggered or was affected by the event. |
| Username | string | Username of the user who triggered the event. |
| Channel ID | string | ID of the channel where the event occurred. |
| Server ID | string | ID of the server where the event occurred. |
| Application ID | string | ID of the application that received the interaction. |
| Interaction ID | string | ID of the interaction. |
| Interaction Token | string | Token used to respond to the interaction. |

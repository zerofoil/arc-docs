---
title: "On WebSocket Open"
---

Runs when a WebSocket connection opens. Set Filter Connection ID to listen for one connection.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Filter Connection ID | string |  | Only handle events from this connection ID. Leave blank for all connections. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Runs when a WebSocket connection opens. |
| Connection ID | string | ID of the WebSocket connection. |
| URL | string | URL used for the WebSocket connection. |

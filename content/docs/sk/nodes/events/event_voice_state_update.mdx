---
title: "On Voice State Changed"
---

A member joins, leaves, or changes voice state

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Runs when a member joins, leaves, or changes voice state. |
| User ID | string | ID of the user who triggered or was affected by the event. |
| Server ID | string | ID of the server where the event occurred. |
| Channel ID | string | ID of the channel where the event occurred. |
| Session ID | string | Voice session ID for the member. |
| Self Muted | boolean | Whether the member muted themself. |
| Self Deafened | boolean | Whether the member deafened themself. |
| Self Streaming | boolean | Whether the member is sharing a stream. |

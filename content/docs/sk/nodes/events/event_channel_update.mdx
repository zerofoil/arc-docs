---
title: "On Channel Updated"
---

A channel is updated

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Runs when a channel is updated. |
| Channel ID | string | ID of the channel where the event occurred. |
| Server ID | string | ID of the server where the event occurred. |
| Name | string | Current name of the event target. |
| Channel Type | number | Discord channel type value. |
| Category ID | string | ID of the parent channel or category. |
| Topic | string | Channel topic, if set. |
| Position | number | Channel position in the server. |
| NSFW | boolean | Whether the channel is age restricted. |
| Slowmode | number | Slowmode delay in seconds. |
| Permission Overwrites | array | Channel-specific permission rules. |

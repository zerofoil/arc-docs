title: "On Scheduled Event Deleted"
---

A scheduled event is deleted

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Runs when a scheduled event is deleted. |
| Event ID | string | ID of the scheduled event. |
| Server ID | string | ID of the server where the event occurred. |
| Name | string | Current name of the event target. |
| Status | number | Scheduled event status. |
| Description | string | Scheduled event description. |
| Channel ID | string | Voice or stage channel for the event. |
| Creator ID | string | User who created the event. |
| Starts At | string | Scheduled start time. |
| Ends At | string | Scheduled end time, if set. |
| Event Type | number | Scheduled event location type. |
| Location ID | string | Voice or stage channel ID. |
| Interested Users | number | Users interested in attending. |

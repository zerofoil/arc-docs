---
title: "On Server Available"
---

The app becomes available in a server

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Runs when the app becomes available in a server. |
| Server ID | string | ID of the server where the event occurred. |
| Name | string | Current name of the event target. |
| Member Count | number | Number of server members, when available. |

---
title: "On AutoMod Action"
---

AutoMod takes action on content

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Runs when AutoMod takes action on content. |
| Rule ID | string | ID of the AutoMod rule that matched. |
| User ID | string | ID of the user who triggered or was affected by the event. |
| Server ID | string | ID of the server where the event occurred. |
| Channel ID | string | ID of the channel where the event occurred. |
| Action Type | number | Discord audit log action type value. |
| Matched Keyword | string | Keyword that triggered the AutoMod rule. |

---
title: "On Presence Updated"
---

A member presence or status changes

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Runs when a member presence or status changes. |
| User ID | string | ID of the user who triggered or was affected by the event. |
| Server ID | string | ID of the server where the event occurred. |
| Status | string | Current presence status of the user. |

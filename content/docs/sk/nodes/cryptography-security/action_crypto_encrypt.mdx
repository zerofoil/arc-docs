---
title: "AES-256-GCM Encrypt"
---

Encrypts data using authenticated AES-256-GCM with PBKDF2

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts encryption of the input text. |
| Plaintext | string |  | Text to encrypt into an authenticated envelope. |
| Passphrase (Optional) | string |  | Optional passphrase used to derive the encryption key. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after encryption finishes. |
| Encrypted Envelope | string | AES-256-GCM envelope containing the encrypted text. |

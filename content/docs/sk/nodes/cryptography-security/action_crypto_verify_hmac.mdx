---
title: "Verify HMAC"
---

Constant-time verification of HMAC signatures

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec | Žiadna | Starts signature verification. |
| Payload | string | Žiadna | Text that was signed. |
| Secret Key | string | Žiadna | Secret key used to create the expected signature. |
| Expected Signature | string | Žiadna | HMAC signature to verify. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after the signature is checked. |
| Is Valid | boolean | True when the signature matches the input and secret. |

---
title: "Respond to Web Request"
---

Send the response for an On Web Request event. Use If / Else to choose status, content type, headers, and body.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota |
| :-: | :-: | :-: |
| Exec | exec |  |
| Request ID | string |  |
| Status | number | 200 |
| Content Type | string | application/json; charset=utf-8 |
| Headers (JSON) | string | \{\} |
| Body | any |  |

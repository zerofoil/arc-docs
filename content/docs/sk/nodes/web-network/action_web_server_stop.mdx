---
title: "Stop All Web Servers"
---

Stop every web server started by this project.

## Vstupy

| Názov Pinu | Typ Pinu | Predvolená Hodnota | Popis Pinu |
| :-: | :-: | :-: | :-: |
| Exec | exec | Žiadna | Stops every web server started by this project. |

## Výstupy

| Názov Pinu | Typ Pinu | Popis Pinu |
| :-: | :-: | :-: |
| Exec | exec | Continues after the project web servers stop. |
| Stopped Count | number | Number of web servers stopped. |
| Error | string | Error message, if a web server could not be stopped. |

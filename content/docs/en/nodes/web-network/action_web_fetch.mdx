---
title: "HTTP Request"
---

Make a bounded HTTP request with headers and an optional body. Local/private network destinations and redirects are blocked.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| URL | string |  |
| Method | string | GET |
| Headers (JSON) | string | \{\} |
| User-Agent | string |  |
| Body | string |  |
| Timeout (ms) | number | 10000 |
| Max response bytes | number | 1048576 |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Exec | exec |
| Status | number |
| Success (2xx) | boolean |
| Response Body | string |
| Response Headers (JSON) | string |
| JSON | object |
| Error | string |

---
title: "Respond to Web Request"
---

Send the response for an On Web Request event. Use If / Else to choose status, content type, headers, and body.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts sending the HTTP response. |
| Request ID | string | None | ID of the request to respond to. |
| Status | number | 200 | HTTP status code to send. |
| Content Type | string | application/json; charset=utf-8 | MIME type of the response body. |
| Headers (JSON) | string | \{\} | Response headers encoded as a JSON object. |
| Body | any | None | Response body sent to the requester. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after the response is handled. |
| Responded | boolean | True when the response was sent. |
| Error | string | Error message, if the response could not be sent. |

---
title: "Add Web Route"
---

Register one API or page route on a started project web server. Route templates only read safe request values.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts registering a route on the web server. |
| Server ID | string | None | ID of the running web server. |
| HTTP Method | string | GET | HTTP method accepted by the route. |
| Path | string | /api/hello | URL path template for the route. |
| Response Status | number | 200 | HTTP status code returned by the route. |
| Content Type | string | application/json; charset=utf-8 | MIME type of the route response. |
| Response Headers (JSON) | string | \{\} | Response headers encoded as a JSON object. |
| Bearer Token | string | None | Token required to access the route. Supports text templates and connected values. |
| Response Template | string | \{"ok":true\} | Response template for the route. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after the route is registered. |
| Registered | boolean | True when the route was registered. |
| Error | string | Error message, if the route could not be registered. |

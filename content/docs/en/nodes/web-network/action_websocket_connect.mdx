---
title: "Connect WebSocket"
---

Opens a WebSocket connection to a public host and waits until it is ready.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts opening the WebSocket connection. |
| Connection ID | string | main | ID to assign to the new connection. |
| WebSocket URL | string | None | Public WebSocket URL to connect to. |
| Protocols | string | None | Optional WebSocket subprotocols. |
| Connect Timeout (ms) | number | 10000 | Maximum time to wait for the connection to open, in milliseconds. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Connected | exec | Runs when the connection opens. |
| Failed | exec | Runs when the connection cannot be opened. |
| Connection ID | string | ID assigned to the opened connection. |
| Connected | boolean | True when the connection opened successfully. |
| Error | string | Error message, if the connection could not be opened. |

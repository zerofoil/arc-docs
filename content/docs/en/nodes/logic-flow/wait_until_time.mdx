---
title: "Wait Until Time"
---

Waits until an ISO date/time or Unix timestamp in milliseconds. Maximum wait is 7 days.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts waiting for the target time. |
| Time (ISO or ms) | string | None | ISO date or Unix timestamp in milliseconds to wait for. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues when the target time is reached. |

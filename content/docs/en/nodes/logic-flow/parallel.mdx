---
title: "Parallel"
---

Runs multiple execution branches concurrently. All branches must connect to the same Join node before execution continues.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts all connected branches concurrently. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Branch 1 | exec | Starts the first concurrent branch. |
| Branch 2 | exec | Starts the second concurrent branch. |

---
title: "Boolean XOR"
---

True when exactly one input is true

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| A | boolean | false | First boolean value to test. |
| B | boolean | false | Second boolean value to test. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | boolean | True when exactly one input is true. |

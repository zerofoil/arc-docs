---
title: "Compare Text"
---

Compares two text strings (equals, contains, startsWith)

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Text A | string |  | First text value to compare. |
| Text B | string |  | Second text value to compare. |
| Operator | string | equals | Comparison to perform on the two text values. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | boolean | True when the selected text comparison matches. |

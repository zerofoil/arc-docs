---
title: "Repeat While"
---

While Condition is true, waits at least 100 ms, runs Body once, and checks again. It can run indefinitely. Route changes through shared graph variables or other live inputs to stop it.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts checking the loop condition. |
| Condition | boolean | true | Repeats the Body branch while this value is true. |
| Interval (ms) | number | 500 | Time to wait before each check and iteration, in milliseconds. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Body | exec | Runs once for each loop iteration. |
| Completed | exec | Runs when the condition becomes false. |
| Iteration | number | One-based number of the current iteration. |

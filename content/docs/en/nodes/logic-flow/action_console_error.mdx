---
title: "Console Error"
---

Writes a message to the Studio console at error level.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Writes the message to the error log. |
| Message | string |  | Text to write to the Studio console. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after the error message is logged. |

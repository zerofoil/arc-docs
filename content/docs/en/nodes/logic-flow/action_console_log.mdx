---
title: "Console Log"
---

Writes a message to the Studio console at info level.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Writes the message to the info log. |
| Message | string | None | Text to write to the Studio console. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after the message is logged. |

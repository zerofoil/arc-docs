---
title: "Boolean AND"
---

True when both inputs are true

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| A | boolean | None | First boolean value to test. |
| B | boolean | None | Second boolean value to test. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | boolean | True only when both inputs are true. |

---
title: "Branch (If / Else)"
---

Splits execution flow based on a boolean condition

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Evaluates the condition and selects an execution branch. |
| Condition | boolean | None | Boolean value used to choose the True or False branch. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| True | exec | Runs when the condition is true. |
| False | exec | Runs when the condition is false. |

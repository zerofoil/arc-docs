---
title: "Wire Extender"
---

Passes execution or any typed data value straight through. Use it to route wires neatly around a busy canvas.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec In | exec | None | Execution flow to pass through the node. |
| Any Value 1 | any | None | Any typed data value to pass through the node. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec Out | exec | Execution flow passed through unchanged. |
| Any Value 1 | any | Data value passed through unchanged. |

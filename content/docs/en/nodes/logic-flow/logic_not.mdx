---
title: "Boolean NOT"
---

Inverts a boolean value

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Value | boolean | None | Boolean value to invert. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | boolean | The opposite of the input boolean. |

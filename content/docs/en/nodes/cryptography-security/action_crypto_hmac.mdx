---
title: "HMAC Sign"
---

Generates HMAC signatures for API & webhook verification

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts HMAC signing. |
| Payload | string | None | Text to sign. |
| Secret Key | string | None | Secret key used to create the signature. |
| Algorithm | string | sha256 | Hash algorithm used for HMAC. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after the signature is created. |
| Signature | string | Hexadecimal HMAC signature for the input text. |

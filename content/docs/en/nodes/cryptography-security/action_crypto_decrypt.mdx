---
title: "AES-256-GCM Decrypt"
---

Decrypts and verifies AES-256-GCM authenticated envelopes

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts decryption of the encrypted envelope. |
| Encrypted Envelope | string | None | AES-256-GCM envelope to decrypt and authenticate. |
| Passphrase (Optional) | string | None | Optional passphrase used to derive the decryption key. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after decryption finishes. |
| Plaintext | string | Authenticated plaintext from the envelope. |

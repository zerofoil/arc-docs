---
title: "Get Variable"
---

Reads a graph variable as typed data

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Variable | variable |  | Variable to read. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Variable | variable | Reference to the variable that was read. |
| Value | string | Current value stored in the variable. |

---
title: "Create Variable"
---

Creates a graph or project variable when the graph runs. An existing variable with the same name is left untouched.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Name | arg |  |
| Value | arg |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Exec | exec |
| Variable | variable |
| Value | arg |

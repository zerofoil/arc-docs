---
title: "Create Variable"
---

Creates a graph or project variable when the graph runs. An existing variable with the same name is left untouched.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts variable creation. |
| Name | arg | None | Name for the new graph or project variable. |
| Value | arg | None | Initial value assigned when the variable is created. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after the variable is available. |
| Variable | variable | Reference to the created or existing variable. |
| Value | arg | Initial value of the created variable. |

---
title: "Absolute (abs)"
---

Returns the distance from zero

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Value | number | None | Number whose distance from zero to return. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | number | Non-negative distance of the input from zero. |

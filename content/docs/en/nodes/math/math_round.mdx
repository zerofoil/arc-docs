---
title: "Round"
---

Rounds to the selected decimal places

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Value | number | 0 | Number to round to the selected decimal places. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | number | Input rounded to the selected decimal places. |

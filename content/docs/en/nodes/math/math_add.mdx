---
title: "Add (+)"
---

Adds two numbers

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| A | number | 0 | First number to add. |
| B | number | 0 | Second number to add. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | number | Sum of A and B. |

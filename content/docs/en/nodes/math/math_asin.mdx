---
title: "Arcsine"
---

Inverse sine, returned in radians

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Value | number | 0 | Sine value to convert to an angle in radians. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | number | Angle in radians whose sine is the input. |

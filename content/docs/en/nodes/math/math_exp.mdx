---
title: "Exponential"
---

Raises Euler’s number to the input power

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Value | number | 0 | Power to raise Euler’s number to. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | number | Euler’s number raised to the input power. |

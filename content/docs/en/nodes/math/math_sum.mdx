---
title: "Sum"
---

Adds up to 50 values. Connect the last input to reveal another.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| A | number | None | First number included in the sum. |
| B | number | None | Second number included in the sum. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | number | Sum of the connected numbers. |

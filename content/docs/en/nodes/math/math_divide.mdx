---
title: "Divide (÷)"
---

Divides A by B, division by zero returns 0

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| A | number | 0 | Number to divide. |
| B | number | 0 | Number to divide by. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | number | A divided by B, or zero when B is zero. |

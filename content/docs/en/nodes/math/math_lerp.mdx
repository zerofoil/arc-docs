---
title: "Interpolate"
---

Linearly interpolates between A and B using a factor from 0 to 1

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| A | number | 0 | Starting value of the interpolation. |
| B | number | 1 | Ending value of the interpolation. |
| Factor | number | 0.5 | Interpolation amount, from 0 to 1. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | number | Value interpolated between A and B. |

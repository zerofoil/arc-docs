---
title: "Power (^)"
---

Raises A to the power of B

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| A | number | 0 | Number to raise to a power. |
| B | number | 0 | Exponent to raise A by. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | number | A raised to the power of B. |

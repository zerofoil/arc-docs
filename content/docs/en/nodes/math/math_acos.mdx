---
title: "Arccosine"
---

Inverse cosine, returned in radians

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Value | number | None | Cosine value to convert to an angle in radians. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | number | Angle in radians whose cosine is the input. |

---
title: "Ceiling"
---

Rounds up to an integer

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Value | number | None | Number to round up to the next integer. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | number | Input rounded up to an integer. |

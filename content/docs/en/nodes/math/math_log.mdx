---
title: "Natural Log"
---

Natural logarithm, non-positive input returns 0

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Value | number | None | Positive number whose natural logarithm to calculate. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | number | Natural logarithm of the input, or zero for non-positive input. |

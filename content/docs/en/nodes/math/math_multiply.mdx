---
title: "Multiply (×)"
---

Multiplies two numbers

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| A | number | 0 | First number to multiply. |
| B | number | 0 | Second number to multiply. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | number | Product of A and B. |

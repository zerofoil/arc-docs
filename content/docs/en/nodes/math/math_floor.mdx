---
title: "Floor"
---

Rounds down to an integer

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Value | number | None | Number to round down to the next integer. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | number | Input rounded down to an integer. |

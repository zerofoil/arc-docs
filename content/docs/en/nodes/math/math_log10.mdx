---
title: "Log Base 10"
---

Base 10 logarithm, non-positive input returns 0

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Value | number | None | Positive number whose base 10 logarithm to calculate. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | number | Base 10 logarithm of the input, or zero for non-positive input. |

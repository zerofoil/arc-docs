---
title: "Maximum (max)"
---

Returns the larger number

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| A | number | None | First number to compare. |
| B | number | None | Second number to compare. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | number | Larger of A and B. |

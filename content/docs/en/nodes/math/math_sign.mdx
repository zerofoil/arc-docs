---
title: "Sign"
---

Returns -1, 0, or 1 for the input sign

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Value | number | None | Number whose sign to check. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | number | -1 for negative, 0 for zero, or 1 for positive input. |

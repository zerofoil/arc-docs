---
title: "Subtract (−)"
---

Subtracts B from A

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| A | number | 0 | Number to subtract from. |
| B | number | 0 | Number to subtract. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | number | A minus B. |

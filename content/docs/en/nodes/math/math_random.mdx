---
title: "Random Number"
---

Returns a random number between the connected minimum and maximum

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Minimum | number | 0 | Lowest possible random value. |
| Maximum | number | 1 | Highest possible random value. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Result | number | Random number between the minimum and maximum. |

---
title: "Regular Expression"
---

Tests, extracts, or replaces text with a JavaScript regular expression. Inputs are bounded and risky regex structures are rejected.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Text | string |  |
| Pattern | string |  |
| Flags | string |  |
| Replacement | string |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Text | string |
| Matched | boolean |
| First Match | string |
| All Matches | object |
| Capture Groups | object |
| Named Captures | object |
| Index | number |
| Valid | boolean |
| Error | string |

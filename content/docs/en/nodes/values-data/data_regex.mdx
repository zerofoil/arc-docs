---
title: "Regular Expression"
---

Tests, extracts, or replaces text with a JavaScript regular expression. Inputs are bounded and risky regex structures are rejected.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Text | string | None | Text to test, extract from, or replace. |
| Pattern | string | None | JavaScript regular expression pattern. |
| Flags | string | None | Regular expression flags. Separate flags with commas or spaces, such as g, i. |
| Replacement | string | None | Text placed in place of each match, limited to 2,000 characters. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Text | string | Resulting text after a test or replacement. |
| Matched | boolean | True when the pattern matches the input. |
| First Match | string | Text of the first match. |
| All Matches | object | Up to 1,000 matched text values. |
| Capture Groups | object | Capture groups from the first match. |
| Named Captures | object | Named capture groups from the first match. |
| Index | number | Zero-based position of the first match. |
| Valid | boolean | True when the pattern and flags are valid. |
| Error | string | Error details when the pattern is invalid or rejected. |

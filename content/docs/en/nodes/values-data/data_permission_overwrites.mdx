---
title: "Channel Permission Overwrites"
---

Builds structured channel access rules. Choose a role or member, then select which channel permissions it can allow or deny.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Target ID 1 | string | None | First role or member ID to configure an access rule. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Overwrites | object | Structured channel permission overwrite rules. |

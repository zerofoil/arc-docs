---
title: "Append Array Items"
---

Returns a copy with connected items appended in socket order. Connect an item to reveal another socket, up to 50, chain another Append Array Items node for more.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Array | object | None | Array to copy and append an item to. |
| Item 1 | arg | None | First value to append to the array. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Array | object | Copy of the input array with connected items appended. |
| Length | number | Number of items in the resulting array. |

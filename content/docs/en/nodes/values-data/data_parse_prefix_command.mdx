---
title: "Parse Prefix Command"
---

Checks for a prefix, extracts the command, and parses whitespace-separated arguments. Quoted arguments can contain spaces.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Message Content | string |  | Message text to check and parse. |
| Prefix | string | ! | Prefix that marks the start of a command. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Recognized | boolean | True when the message starts with the prefix and contains a command. |
| Command | string | Command name after the prefix. |
| Arguments | object | Whitespace-separated command arguments. |
| Argument Count | number | Number of parsed arguments. |

---
title: "Edit Array Item"
---

Returns a copy of the array with an existing zero-based index replaced. The source array is unchanged.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Array | object | None | Array to copy and update. |
| Index | number | None | Zero-based position of the item to replace. |
| New Item | arg | None | Value to place at the selected index. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Array | object | Copy of the array with the selected item replaced. |
| Updated | boolean | True when an existing array item was replaced. |

---
title: "Current Timestamp"
---

Returns the current Unix timestamp in milliseconds and the matching UTC ISO 8601 date.

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Unix timestamp (ms) | number | Current Unix timestamp in milliseconds. |
| ISO date | string | Current date and time in UTC ISO 8601 format. |

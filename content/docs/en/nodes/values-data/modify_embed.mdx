---
title: "Modify Embed"
---

Updates specific fields on an existing embed without rebuilding it

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Base Embed | embed |  | Embed to copy and update. |
| Title (Optional) | string |  | Optional replacement title. |
| Description (Optional) | string |  | Optional replacement description. |
| Hex Color (#, optional) | string |  | Optional replacement hex color. |
| Image URL (Optional) | string |  | Optional replacement image URL. |
| Thumbnail URL (Optional) | string |  | Optional replacement thumbnail URL. |
| Footer Text (Optional) | string |  | Optional replacement footer text. |
| Author Name (Optional) | string |  | Optional replacement author name. |
| Field Name (Optional) | string |  | Optional field name to add or update. |
| Field Value (Optional) | string |  | Optional field value to add or update. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Embed | embed | Updated embed with the selected fields changed. |

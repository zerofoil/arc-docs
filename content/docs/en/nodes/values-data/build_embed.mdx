---
title: "Embed Builder"
---

Constructs a rich Discord embed object

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Title | string | None | Embed title text. |
| Description | string | None | Main description text for the embed. |
| URL | string | None | URL opened when the title is clicked. |
| Hex Color (#) | string | #5865F2 | Embed accent color as a hex value. |
| Author | string | None | Author name shown above the description. |
| Author URL | string | None | URL opened when the author name is clicked. |
| Author Icon URL | string | None | URL of the author icon image. |
| Footer Text | string | None | Footer text shown at the bottom. |
| Footer Icon URL | string | None | URL of the footer icon image. |
| Thumbnail URL | string | None | URL of the thumbnail image. |
| Image URL | string | None | URL of the main embed image. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Embed | embed | Built Discord embed object. |
| Components | object | Message components attached to the embed. |

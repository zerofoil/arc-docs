---
title: "Embed Builder"
---

Constructs a rich Discord embed object

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Title | string |  | Embed title text. |
| Description | string |  | Main description text for the embed. |
| URL | string |  | URL opened when the title is clicked. |
| Hex Color (#) | string | #5865F2 | Embed accent color as a hex value. |
| Author | string |  | Author name shown above the description. |
| Author URL | string |  | URL opened when the author name is clicked. |
| Author Icon URL | string |  | URL of the author icon image. |
| Footer Text | string |  | Footer text shown at the bottom. |
| Footer Icon URL | string |  | URL of the footer icon image. |
| Thumbnail URL | string |  | URL of the thumbnail image. |
| Image URL | string |  | URL of the main embed image. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Embed | embed | Built Discord embed object. |
| Components | object | Message components attached to the embed. |

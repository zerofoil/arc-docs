---
title: "Modify Components"
---

Updates legacy message buttons and select menus. Use Modify Components V2 for Components V2 layouts.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Components | object |  |
| Target Custom ID ("all" for all) | string | all |
| Disabled | boolean | true |
| New Label (Optional) | string |  |
| New Style (Optional) | string |  |
| New Placeholder (Select Menus) | string |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Components | object |

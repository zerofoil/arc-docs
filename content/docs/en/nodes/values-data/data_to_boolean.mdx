---
title: "To Boolean"
---

Converts booleans, numbers, and common text values (true/false, yes/no, 1/0, on/off). Unknown text returns false; check Valid.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Value | arg | false | Boolean, number, or text value to convert. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Boolean | boolean | Converted boolean value. |
| Valid | boolean | True when the input contains a recognized boolean value. |

---
title: "Find Array Item"
---

Finds the first item equal to Value. Set Path to compare a nested property, such as id or user.name.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Array | object | None | Array to search. |
| Property path | string | None | Optional property path to compare on each item. |
| Match value | arg | None | Value to find in the array or selected property. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Item | arg | First matching item, when found. |
| Index | number | Zero-based position of the first matching item. |
| Found | boolean | True when a matching item exists. |

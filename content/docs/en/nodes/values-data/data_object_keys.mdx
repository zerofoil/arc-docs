---
title: "Object Keys"
---

Returns the enumerable property names of an object as an array.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Object | object | [object Object] | Object whose property names to list. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Keys | object | Enumerable property names from the object. |
| Length | number | Number of property names in the result. |

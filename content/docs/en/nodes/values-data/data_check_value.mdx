---
title: "Check Value"
---

Distinguishes missing, null, empty text, and real values. The Value output uses the fallback unless a real value is present.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Value | arg |  | Value to check for missing, null, empty, or present state. |
| Fallback | arg |  | Value to return when the input is missing, null, or empty. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Value or fallback | arg | Original value when present, otherwise the fallback. |
| State | string | State detected for the input value. |
| Missing | boolean | True when the input value is missing. |
| Null | boolean | True when the input value is null. |
| Empty text | boolean | True when the input is empty text. |
| Has value | boolean | True when the input contains a usable value. |

---
title: "Get Modal Value"
---

Reads a submitted modal field by custom ID, multi-select fields return arrays.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Submitted Values | object | None | Submitted values from the modal interaction. |
| Field Custom ID | string | None | Custom ID of the submitted modal field. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Value | object | Value submitted for the matching field. |
| Found | boolean | True when a field with this custom ID was submitted. |

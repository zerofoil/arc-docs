---
title: "Parse JSON"
---

Parses JSON text into a value. Check Valid before using the parsed output.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| JSON | string |  | JSON text to parse. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Value | object | Parsed value when the JSON text is valid. |
| Valid | boolean | True when the input contains valid JSON. |

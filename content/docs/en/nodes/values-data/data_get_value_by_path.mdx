---
title: "Get Value by Path"
---

Safely reads a nested object or array path such as user.profile.name or items[0].id. Check Exists when the path may be missing.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Object / Array | object | [object Object] | Object or array to read from. |
| Path | string | None | Property path to read, such as user.name or items[0].id. |
| Fallback | arg | None | Value to return when the path does not exist. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Value or fallback | arg | Value at the path, or the fallback when the path is missing. |
| Exists | boolean | True when the path exists. |

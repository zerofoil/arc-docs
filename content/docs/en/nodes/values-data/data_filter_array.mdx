---
title: "Filter Array"
---

Keeps items whose value (or selected property path) matches the chosen comparison.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Array | object | None | Array whose items to test. |
| Property path | string | None | Optional property path to read from each item. |
| Comparison | string | equals | Comparison to apply to each item or property. |
| Match value | arg | None | Value used for the selected comparison. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Filtered items | object | Items that match the selected comparison. |
| Count | number | Number of items that matched. |

---
title: "Array Length"
---

Returns the number of items in an array and whether it is empty.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Array | object | None | Array whose length and empty state to check. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Length | number | Number of items in the array. |
| Is Empty | boolean | True when the array has no items. |

---
title: "Uppercase Text"
---

Converts text to uppercase.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Text | string | None | Text to convert to uppercase. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Text | string | Input text converted to uppercase. |

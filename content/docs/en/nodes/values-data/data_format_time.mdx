---
title: "Format Date & Time"
---

Formats an ISO date or Unix millisecond timestamp using a locale, time zone, and date/time styles.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Date / Timestamp | arg | None | ISO date or Unix timestamp in milliseconds to format. |
| Time zone | string | UTC | Time zone used to format the date. |
| Date Format | string | DD/MM/YYYY - HH:mm:ss | Date or time display style. |
| Is Duration | boolean | None | Treat the input as a duration instead of a date. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Formatted time | string | Formatted date, time, or duration text. |
| Valid | boolean | True when the input and formatting options are valid. |

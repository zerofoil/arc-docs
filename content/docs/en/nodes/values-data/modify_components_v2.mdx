---
title: "Modify Components V2"
---

Changes one Components V2 block field while preserving the rest of the layout. Connect the result to a message or interaction reply.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Components V2 | object | None | Components V2 layout to copy and update. |
| Block ID (all for matching blocks) | string | all | ID of the block to update, or all to update matching blocks. |
| Property | string | spoiler | Block property to change. |
| Media Item Index (-1 for all) | number | -1 | Zero-based media item index, or -1 to update all media items. |
| Value | any | None | New value for the selected property. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Components V2 | object | Updated Components V2 layout. |

---
title: "Create Array"
---

Collects connected values in order. One extra socket appears as you use each socket, up to 50 items, use Combine Arrays to combine arrays.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Item 1 | arg | None | First value to include in the new array. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Array | object | New array containing the connected values in order. |
| Length | number | Number of values in the new array. |

---
title: "Replace Text"
---

Replaces literal occurrences of a search string and reports how many replacements were made.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Text | string |  | Text to search and update. |
| Find | string |  | Exact text to find. |
| Replace with | string |  | Text to put in place of each match. |
| Find All / Replace All | boolean | true | Replace every match instead of only the first. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Text | string | Text after the matching content is replaced. |
| Replacements | number | Number of replacements made. |

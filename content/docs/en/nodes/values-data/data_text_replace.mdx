---
title: "Replace Text"
---

Replaces literal occurrences of a search string and reports how many replacements were made.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Text | string |  |
| Find | string |  |
| Replace with | string |  |
| Find All / Replace All | boolean | true |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Text | string |
| Replacements | number |

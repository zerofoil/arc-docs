---
title: "Title Case Text"
---

Capitalizes the first letter of each word.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Text | string | None | Text whose words to capitalize. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Text | string | Text with the first letter of each word capitalized. |

---
title: "Call Function"
---

Runs a reusable function graph and returns its result

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts the function graph. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after the function returns. |
| Result | number | Value returned by the called function. |

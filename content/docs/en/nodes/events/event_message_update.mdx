---
title: "On Message Updated"
---

A message is edited

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Runs when a message is edited. |
| Message Payload (May Be Partial) | object | The updated message payload, which may be partial. |
| Message ID | string | ID of the message tied to this event. |
| Channel ID | string | ID of the channel where the event occurred. |
| Server ID | string | ID of the server where the event occurred. |
| Author ID | string | ID of the message author. |
| Content | string | Text content of the message. |
| Edited At | string | Time when the message was last edited. |

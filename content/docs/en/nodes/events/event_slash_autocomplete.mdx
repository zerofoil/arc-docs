---
title: "On Command Autocomplete"
---

Runs while a user types an autocomplete-enabled slash command option.

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Runs while a user types an autocomplete-enabled command option. |
| Command Name | string | Name of the invoked application command. |
| Focused Option | string | Name of the command option being completed. |
| Typed Text | string | Text entered for the focused option. |
| Other Arguments | object | Arguments submitted with the command. |
| User ID | string | ID of the user who triggered or was affected by the event. |
| Channel ID | string | ID of the channel where the event occurred. |
| Server ID | string | ID of the server where the event occurred. |
| Interaction ID | string | ID of the interaction. |
| Interaction Token | string | Token used to respond to the interaction. |

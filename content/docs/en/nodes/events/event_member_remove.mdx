---
title: "On Member Left"
---

A user leaves a server

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Runs when a user leaves a server. |
| User ID | string | ID of the user who triggered or was affected by the event. |
| Server ID | string | ID of the server where the event occurred. |
| User | object | User data sent with the event. |
| Username | string | User's account name. |
| Display Name | string | User's display name, if set. |
| Is Bot | boolean | Whether the user is a bot. |

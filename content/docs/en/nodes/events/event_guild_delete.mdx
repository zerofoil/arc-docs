---
title: "On Server Unavailable"
---

A server becomes unavailable

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Runs when a server becomes unavailable. |
| Server ID | string | ID of the server where the event occurred. |
| Unavailable | boolean | Whether the server is temporarily unavailable. |

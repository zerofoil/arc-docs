---
title: "On Audit Log Entry Created"
---

An audit log entry is created. Requires View Audit Log. Discord may merge channel or role position updates, and merged updates may not emit another event.

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Runs when an audit log entry is created. |
| Audit Log Entry ID | string | ID of the audit log entry. |
| Server ID | string | ID of the server where the event occurred. |
| Action Type ID | number | Discord audit log action type value. |
| Target ID | string | ID of the object changed by the action. |
| Acting User ID | string | ID of the user who triggered or was affected by the event. |
| Reason | string | Reason recorded with the audit log entry. |
| Changes | array | Fields changed in the audit log entry. |
| Options | object | Arguments submitted with the command. |
| Full Audit Log Entry | object | Full audit log entry. |

---
title: "On Button Click"
---

Fires when a message component button is pressed

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Runs when a message component button is pressed. |
| Source Message Object | object | The message containing the submitted component. |
| Message ID | string | ID of the message tied to this event. |
| Custom ID | string | Custom ID of the submitted component. |
| User ID | string | ID of the user who triggered or was affected by the event. |
| Server ID | string | ID of the server where the event occurred. |
| Channel ID | string | ID of the channel where the event occurred. |
| Thread ID | string | ID of the thread where the event occurred. |
| Application ID | string | ID of the application that received the interaction. |
| Interaction ID | string | ID of the interaction. |
| Interaction Token | string | Token used to respond to the interaction. |

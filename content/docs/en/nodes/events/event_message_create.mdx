---
title: "On Message Create"
---

Fires for every new message. Server ID is empty in direct messages. Use Split Text to break message content into parts.

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Runs for every new message. |
| Message Object | object | The new Discord message. |
| Message ID | string | ID of the message tied to this event. |
| Message Content | string | Text content of the message. |
| Author ID | string | ID of the message author. |
| Author Name | string | Username of the message author. |
| Channel ID | string | ID of the channel where the event occurred. |
| Thread ID | string | ID of the thread where the event occurred. |
| Server ID | string | ID of the server where the event occurred. |
| Is Bot | boolean | Whether the message author is a bot. |
| Has Mentions | boolean | Whether the message mentions any users. |
| Mentioned Users | object | Users mentioned in the message. |
| Mentioned Roles | object | Roles mentioned in the message. |
| Mentions Everyone | boolean | Whether the message mentions everyone. |
| Is Reply | boolean | Whether the message replies to another message. |
| Replied Message ID | string | ID of the message being replied to. |
| Replied Author ID | string | ID of the author of the replied message. |

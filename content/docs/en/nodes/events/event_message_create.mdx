---
title: "On Message Create"
---

Fires for every new message. Server ID is empty in direct messages. Use Split Text to break message content into parts.

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Exec | exec |
| Message Object | object |
| Message ID | string |
| Message Content | string |
| Author ID | string |
| Author Name | string |
| Channel ID | string |
| Thread ID | string |
| Server ID | string |
| Is Bot | boolean |
| Has Mentions | boolean |
| Mentioned Users | object |
| Mentioned Roles | object |
| Mentions Everyone | boolean |
| Is Reply | boolean |
| Replied Message ID | string |
| Replied Author ID | string |

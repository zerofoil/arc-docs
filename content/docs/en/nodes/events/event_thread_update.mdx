---
title: "On Thread Updated"
---

A thread is updated

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Runs when a thread is updated. |
| Thread ID | string | ID of the thread where the event occurred. |
| Server ID | string | ID of the server where the event occurred. |
| Parent Channel ID | string | ID of the parent channel or category. |
| Name | string | Current name of the event target. |
| Channel Type | number | Discord channel type value. |
| Owner ID | string | ID of the thread creator. |
| Message Count | number | Messages in the thread. |
| Member Count | number | Members in the thread. |
| Auto Archive | number | Minutes before the thread is archived. |

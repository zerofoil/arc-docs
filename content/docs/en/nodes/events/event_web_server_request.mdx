---
title: "On Web Request"
---

Fires when an HTTP request matches this route. Connect Server ID from Start Web Server, then use If / Else and Respond to Web Request to build the handler.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Server ID | string |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Exec | exec |
| Request ID | string |
| Server ID | string |
| HTTP Method | string |
| Path | string |
| Query | object |
| Path Parameters | object |
| Request Headers | object |
| Request Body | any |

---
title: "On Web Request"
---

Fires when an HTTP request matches this route. Connect Server ID from Start Web Server, then use If / Else and Respond to Web Request to build the handler.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Server ID | string |  | Only handle requests from this web server ID. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Runs when an HTTP request matches this route. |
| Request ID | string | Unique ID for this HTTP request. |
| Server ID | string | ID of the web server handling this request. |
| HTTP Method | string | HTTP method used by the request. |
| Path | string | Request path without the query string. |
| Query | object | Text entered for the focused option. |
| Path Parameters | object | Route parameters parsed from the request path. |
| Request Headers | object | Headers sent with the request. |
| Request Body | any | Body sent with the request. |

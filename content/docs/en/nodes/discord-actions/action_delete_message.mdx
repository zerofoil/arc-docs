---
title: "Delete Message"
---

Deletes a message from a channel. Requires Manage Messages to delete messages from other users.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts Delete Message. |
| Channel ID | string |  | ID of the channel containing the message. |
| Message ID | string |  | ID of the message to delete. |
| Audit Log Reason | string |  | Reason recorded in the audit log. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after Delete Message completes. |
| Success | boolean | Whether the action completed successfully. |

---
title: "Delete Message"
---

Deletes a message from a channel. Requires Manage Messages to delete messages from other users.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Channel ID | string |  |
| Message ID | string |  |
| Audit Log Reason | string |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Exec | exec |
| Success | boolean |

---
title: "Create Channel"
---

Creates a text, voice, category, announcement, stage, forum, or media channel. Requires Manage Channels.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts Create Channel. |
| Server ID | string | None | ID of the server where the channel will be created. |
| Name | string | None | Name to assign. |
| Channel Type | number | None | Discord channel type value. |
| Category ID | string | None | Category ID alias for the parent channel. |
| Parent ID | string | None | Optional parent channel or category ID. |
| Permission Overwrites | object | None | Channel permission overwrites to apply. |
| Topic | string | None | Channel topic to set. |
| Channel Flags | number | None | Channel flags to set. |
| Slowmode (seconds) | number | None | Slowmode delay in seconds. |
| Bitrate (bits/sec) | number | 64000 | Voice channel bitrate in bits per second. |
| User Limit | number | None | Maximum number of users allowed in the voice channel. |
| Position | number | None | Position of the new channel in the channel list. |
| Voice Region | string | None | Voice region for the new channel, or blank for automatic selection. |
| Voice Video Quality Mode | number | 1 | Voice video quality mode value. |
| Default Thread Archive (minutes) | number | 1440 | Default thread auto archive time in minutes. |
| Thread Slowmode (seconds) | number | None | Default thread slowmode in seconds. |
| Forum Tags | object | None | Forum tags to make available. |
| Age Restricted | boolean | None | Whether to mark the channel as age restricted. |
| Audit Log Reason | string | None | Reason recorded in the audit log. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after Create Channel completes. |
| Channel Object | object | New channel record returned by Discord. |
| Channel ID | string | ID of the created channel. |
| Channel ID | string | ID of the returned channel. |
| Success | boolean | Whether the action completed successfully. |

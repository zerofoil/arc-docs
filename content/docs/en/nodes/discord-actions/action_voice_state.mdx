---
title: "Request Voice Join / Leave"
---

Requests a Gateway voice-state change. Joining does not create an audio connection or play audio.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts Request Voice Join / Leave. |
| Server ID | string | None | ID of the server containing the voice channel. |
| Voice Channel ID (blank leaves) | string | None | Voice channel ID to join, or blank to leave voice. |
| Self Mute | boolean | None | Whether to join voice muted. |
| Self Deafen | boolean | None | Whether to join voice deafened. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after Request Voice Join / Leave completes. |
| Success | boolean | Whether the action completed successfully. |

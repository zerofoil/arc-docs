---
title: "Bulk Delete Messages"
---

Deletes 2 to 100 messages from a server channel. Messages older than 14 days cannot be bulk deleted. Requires Manage Messages.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts Bulk Delete Messages. |
| Channel ID | string | None | ID of the channel containing the messages. |
| Message IDs | object | None | IDs of the messages to delete. |
| Audit Log Reason | string | None | Reason recorded in the audit log. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after Bulk Delete Messages completes. |
| Deleted Count | number | Number of messages deleted. |
| Success | boolean | Whether the action completed successfully. |

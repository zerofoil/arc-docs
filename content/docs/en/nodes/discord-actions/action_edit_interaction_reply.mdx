---
title: "Edit Interaction Reply"
---

Edits the original reply to a slash command, button, or select menu interaction after it has already been sent

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts Edit Interaction Reply. |
| Application ID | string | None | ID of the application that owns the interaction. |
| Interaction Token | string | None | Token used to respond to the interaction. |
| New Content (Optional) | string | None | Replacement text for the original interaction reply. |
| Embed (Optional) | embed | None | Embed to include with the message. |
| Components (Optional) | object | None | Message components to send or update. |
| Files (optional) | object | None | Files to attach to the message. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after Edit Interaction Reply completes. |
| Success | boolean | Whether the action completed successfully. |

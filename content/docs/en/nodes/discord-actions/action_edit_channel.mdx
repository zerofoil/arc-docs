---
title: "Edit Channel"
---

Changes a channel name, topic, category, slowmode, or permissions. Requires Manage Channels.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts Edit Channel. |
| Channel ID | string | None | ID of the channel to edit. |
| Thread ID (Optional) | string | None | Optional thread ID to edit. |
| Name | string | None | Name to assign. |
| Topic | string | None | Channel topic to set. |
| Category ID | string | None | ID of the parent channel or category. |
| Category ID (Alias) | string | None | ID of the parent category. |
| Permission Overwrites | object | None | Channel permission overwrites to apply. |
| Position | number | None | Position of the channel in the channel list. |
| Channel Flags | number | None | Channel flags to set. |
| Slowmode (seconds) | number | None | Slowmode delay in seconds. |
| Thread Slowmode (seconds) | number | None | Default thread slowmode in seconds. |
| Forum Tags | object | None | Forum tags to make available. |
| Age restricted | boolean | None | Whether to mark the channel as age restricted. |
| Voice bitrate | number | 64000 | Voice channel bitrate in bits per second. |
| Voice user limit | number | None | Maximum number of users allowed in the voice channel. |
| Voice Region | string | None | Voice region for the channel, or blank for automatic selection. |
| Voice video quality mode | number | None | Voice video quality mode value. |
| Thread auto archive (minutes) | number | None | Default thread auto archive time in minutes. |
| Archived | boolean | None | Whether to archive the thread. |
| Locked | boolean | None | Whether to lock the thread. |
| Members can invite | boolean | true | Whether thread members can invite others. |
| Thread auto archive (minutes) | number | 1440 | Thread auto archive time in minutes. |
| Audit Log Reason | string | None | Reason recorded in the audit log. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after Edit Channel completes. |
| Channel Object | object | Updated channel record returned by Discord. |
| Channel ID | string | ID of the returned channel. |
| Channel ID | string | ID of the channel to edit. |
| Success | boolean | Whether the action completed successfully. |

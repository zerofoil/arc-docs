---
title: "Edit Channel"
---

Changes a channel name, topic, category, slowmode, or permissions. Requires Manage Channels.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Channel ID | string |  |
| Thread ID (Optional) | string |  |
| Name | string |  |
| Topic | string |  |
| Category ID | string |  |
| Category ID (Alias) | string |  |
| Permission Overwrites | object |  |
| Position | number |  |
| Channel Flags | number |  |
| Slowmode (seconds) | number | 0 |
| Thread Slowmode (seconds) | number |  |
| Forum Tags | object |  |
| Age restricted | boolean | false |
| Voice bitrate | number | 64000 |
| Voice user limit | number | 0 |
| Voice Region | string |  |
| Voice video quality mode | number |  |
| Thread auto archive (minutes) | number |  |
| Archived | boolean | false |
| Locked | boolean | false |
| Members can invite | boolean | true |
| Thread auto archive (minutes) | number | 1440 |
| Audit Log Reason | string |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Exec | exec |
| Channel Object | object |
| Channel ID | string |
| Channel ID | string |
| Success | boolean |

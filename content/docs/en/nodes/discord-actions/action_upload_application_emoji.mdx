---
title: "Upload Bot Emoji"
---

Uploads an emoji to the bot application. Requires a PNG, JPEG, GIF, or WebP image no larger than 256 KiB.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Emoji Name | string |  |
| Image File | object |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Exec | exec |
| Emoji ID | string |
| Emoji Name | string |
| Success | boolean |

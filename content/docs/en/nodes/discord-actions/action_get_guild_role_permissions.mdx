---
title: "Get Guild Role Permissions"
---

Gets a role's combined guild permissions together with the @everyone role.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts Get Guild Role Permissions. |
| Server ID | string | None | ID of the server whose permissions to check. |
| Role ID | string | None | ID of the role whose permissions to check. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after Get Guild Role Permissions completes. |
| Permissions Bitfield | string | Calculated permission bitfield. |
| Success | boolean | Whether the action completed successfully. |

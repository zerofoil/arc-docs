---
title: "Create Role"
---

Creates a role with a name, RGB color number, and mentionable setting. Requires Manage Roles.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts Create Role. |
| Server ID | string | None | ID of the server to receive the new role. |
| Name | string | new role | Name to assign. |
| Color (RGB number) | number | None | Role color as an RGB integer. |
| Permissions Bitfield | string | 0 | Role permission bitfield. |
| Show separately | boolean | None | Whether to show the role separately in the member list. |
| Mentionable | boolean | None | Whether users can mention the role. |
| Audit Log Reason | string | None | Reason recorded in the audit log. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after Create Role completes. |
| Role ID | string | ID of the created role. |
| Success | boolean | Whether the action completed successfully. |

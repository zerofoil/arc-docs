---
title: "Upload Server Emoji"
---

Uploads a PNG, JPEG, GIF, or WebP emoji to a server. Requires Create Expressions and a file no larger than 256 KiB.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts uploading an emoji to the server. |
| Server ID | string |  | ID of the server to receive the emoji. |
| Emoji Name | string |  | Name to assign. |
| Image File | object |  | Files to attach to the message. |
| Role IDs | object |  | Role IDs allowed to use the emoji. |
| Audit Log Reason | string |  | Reason recorded in the audit log. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after Upload Server Emoji completes. |
| Emoji ID | string | ID of the created emoji. |
| Emoji Name | string | Name of the created emoji. |
| Success | boolean | Whether the action completed successfully. |

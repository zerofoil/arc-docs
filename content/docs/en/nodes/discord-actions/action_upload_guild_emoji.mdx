---
title: "Upload Server Emoji"
---

Uploads a PNG, JPEG, GIF, or WebP emoji to a server. Requires Create Expressions and a file no larger than 256 KiB.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Server ID | string |  |
| Emoji Name | string |  |
| Image File | object |  |
| Role IDs | object |  |
| Audit Log Reason | string |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Exec | exec |
| Emoji ID | string |
| Emoji Name | string |
| Success | boolean |

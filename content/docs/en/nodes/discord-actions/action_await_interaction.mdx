---
title: "Await Interaction"
---

Waits for an incoming button click or select menu interaction matching optional filters, with timeout and filter-failed branches.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts Await Interaction. |
| Custom ID | string |  | Custom ID to match on the interaction. |
| User ID | string |  | Only accept interactions from this user. |
| Channel ID | string |  | Only accept interactions from this channel. |
| Message ID | string |  | Only accept interactions from this message. |
| Timeout (s) | number | 60 | Maximum time to wait for a matching interaction. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Success | exec | Continues after Await Interaction completes. |
| Filter Failed | exec | Runs when the interaction does not match the filters. |
| Timeout | exec | Runs when no matching interaction arrives before the timeout. |
| Interaction ID | string | ID of the interaction that was handled. |
| Interaction Token | string | Token used to continue responding to the interaction. |
| Custom ID | string | Custom ID to match on the interaction. |
| User ID | string | ID of the user who interacted. |
| Channel ID | string | ID of the channel where the interaction occurred. |
| Server ID | string | ID of the server where the interaction occurred. |
| Message ID | string | ID of the message that received the interaction. |
| Selected Values | string | Values selected in the received menu. |
| Interaction Object | object | Full interaction received by this node. |

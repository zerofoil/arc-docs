---
title: "Start Thread from Message"
---

Starts a public thread from an existing message in a text channel.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts Start Thread from Message. |
| Parent Channel ID | string | None | ID of the channel containing the message. |
| Message ID | string | None | ID of the message to start a thread from. |
| Thread Name | string | None | Name to assign. |
| Auto Archive (minutes) | number | 1440 | Thread auto archive time in minutes. |
| Slowmode (seconds) | number | None | Slowmode delay in seconds. |
| Audit Log Reason | string | None | Reason recorded in the audit log. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after Start Thread from Message completes. |
| Thread ID | string | ID of the thread created by the action. |
| Parent Channel ID | string | ID of the thread parent channel. |
| Success | boolean | Whether the action completed successfully. |

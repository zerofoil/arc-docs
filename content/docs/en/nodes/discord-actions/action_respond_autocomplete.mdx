---
title: "Respond to Autocomplete"
---

Returns up to 25 suggestions from a wired array of name and value objects.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts Respond to Autocomplete. |
| Interaction ID | string | None | ID of the interaction to respond to. |
| Interaction Token | string | None | Token used to respond to the interaction. |
| Suggestions | object | None | Suggestions to return for the focused command option. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after Respond to Autocomplete completes. |
| Suggestions Sent | number | Number of suggestions sent to Discord. |
| Success | boolean | Whether the action completed successfully. |

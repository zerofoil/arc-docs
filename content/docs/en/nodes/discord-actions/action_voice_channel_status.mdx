---
title: "Set Voice Channel Status"
---

Sets or clears a voice channel status. Requires Set Voice Channel Status, Manage Channels may also be required.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts Set Voice Channel Status. |
| Voice Channel ID | string | None | ID of the voice channel to update. |
| Status (blank clears) | string | None | Status text to set, or blank to clear the current status. |
| Audit Log Reason | string | None | Reason recorded in the audit log. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after Set Voice Channel Status completes. |
| Success | boolean | Whether the action completed successfully. |

---
title: "Edit Message"
---

Edits the content, embed, or components of an existing Discord message

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts Edit Message. |
| Channel ID | string | None | ID of the channel containing the message. |
| Message ID | string | None | ID of the message to edit. |
| Content | string | None | Message text to send or update. |
| Embed (Optional) | embed | None | Embed to include with the message. |
| Components (Optional) | object | None | Message components to send or update. |
| Files (optional) | object | None | Files to attach to the message. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after Edit Message completes. |
| Message ID | string | ID of the message created by the action. |
| Success | boolean | Whether the action completed successfully. |

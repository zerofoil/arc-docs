---
title: "Send Message"
---

Sends message text, embeds, attachments, and interactive components to a Discord channel

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec | None | Starts Send Message. |
| Channel ID | string | None | ID of the channel where the message will be sent. |
| Thread ID (Optional) | string | None | Optional thread ID where the message will be sent. |
| Content | string | None | Message text to send or update. |
| Embed (Optional) | embed | None | Embed to include with the message. |
| Components (Optional) | object | None | Message components to send or update. |
| Files (optional) | object | None | Files to attach to the message. |
| File Data URL / Base64 | string | None | File contents as a data URL or base64 text. |
| File Name | string | image.png | File name shown for the uploaded attachment. |
| Reply to Message ID | string | None | ID of the message to reply to. |
| Mention Replied User | boolean | None | Whether to mention the author of the replied message. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after Send Message completes. |
| Message ID | string | ID of the message created by the action. |
| Success | boolean | Whether the action completed successfully. |

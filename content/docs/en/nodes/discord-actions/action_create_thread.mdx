---
title: "Create Thread"
---

Creates a public or private thread inside a text channel. Requires the matching thread permission.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts Create Thread. |
| Parent Channel ID | string |  | ID of the channel where the thread will be created. |
| Message ID (Optional) | string |  | ID of the message to start a thread from. |
| Thread Name | string |  | Name to assign. |
| Thread Type | number | 11 | Discord thread type value. |
| Auto Archive (minutes) | number | 1440 | Thread auto archive time in minutes. |
| Slowmode (seconds) | number | 0 | Slowmode delay in seconds. |
| Members Can Invite | boolean | true | Whether thread members can invite others. |
| Audit Log Reason | string |  | Reason recorded in the audit log. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after Create Thread completes. |
| Thread ID | string | ID of the thread created by the action. |
| Parent Channel ID | string | ID of the thread parent channel. |
| Success | boolean | Whether the action completed successfully. |

---
title: "Upload Server Sticker"
---

Uploads a PNG, APNG, or GIF sticker to a server. Requires Create Expressions. File limit is 512 KiB.

## Inputs

| Pin Name | Pin Type | Default Value | Pin Description |
| :-: | :-: | :-: | :-: |
| Exec | exec |  | Starts uploading a sticker to the server. |
| Server ID | string |  | ID of the server to receive the sticker. |
| Sticker Name | string |  | Name to assign. |
| Description | string |  | Description to assign. |
| Tags (emoji) | string | ✨ | Emoji tags used to identify the sticker. |
| Sticker File | object |  | Files to attach to the message. |
| Audit Log Reason | string |  | Reason recorded in the audit log. |

## Outputs

| Pin Name | Pin Type | Pin Description |
| :-: | :-: | :-: |
| Exec | exec | Continues after Upload Server Sticker completes. |
| Sticker ID | string | ID of the created sticker. |
| Sticker Name | string | Name of the created sticker. |
| Success | boolean | Whether the action completed successfully. |

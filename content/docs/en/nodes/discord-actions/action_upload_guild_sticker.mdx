---
title: "Upload Server Sticker"
---

Uploads a PNG, APNG, or GIF sticker to a server. Requires Create Expressions. File limit is 512 KiB.

## Inputs

| Pin Name | Pin Type | Default Value |
| :-: | :-: | :-: |
| Exec | exec |  |
| Server ID | string |  |
| Sticker Name | string |  |
| Description | string |  |
| Tags (emoji) | string | ✨ |
| Sticker File | object |  |
| Audit Log Reason | string |  |

## Outputs

| Pin Name | Pin Type |
| :-: | :-: |
| Exec | exec |
| Sticker ID | string |
| Sticker Name | string |
| Success | boolean |
